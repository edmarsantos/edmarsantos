## 👨‍💻 Sobre mim

Sou desenvolvedor de software com foco em **Backend Java e Spring Boot**, atuando na construção e evolução de aplicações corporativas, integrações entre sistemas, automações e soluções orientadas a dados.

Minha trajetória em desenvolvimento também inclui experiência com sistemas legados em **ASP.NET / VB.NET**, desenvolvimento web, APIs e bancos de dados, o que me permite compreender tanto ambientes existentes quanto arquiteturas modernas.

🎓 Pós-graduado em **Arquitetura de Software pela FIAP**, com estudos envolvendo:

- Domain-Driven Design (DDD)
- Clean Architecture
- Arquitetura Hexagonal
- Microsserviços
- Mensageria
- Docker e Kubernetes
- Cloud Computing
- CI/CD
- Observabilidade
- Infrastructure as Code

Atualmente também estou direcionando meus estudos para **Inteligência Artificial aplicada ao desenvolvimento de software**, buscando integrar Engenharia de Software, Backend e IA em aplicações corporativas.
